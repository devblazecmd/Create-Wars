# Create Big Cannons

**Source:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-big-cannons)

## Role in Create Wars
This is the core "guns" mod for the pack. Multiblock cannons built from cannon blocks across multiple
material tiers, multiblock autocannons for faster fire rate, a range of projectile types, kinetic-powered
loading/aiming mechanisms, and fuze items for detonation behavior. Explicitly designed with multiplayer PvP
in mind — a good sign for the "fight each other or the mobs" goal.

## Dependencies
- Hard requires: [[Create]] v6.0.7 or newer (check this against whatever Create version we actually pin —
  the addon has historically required a newer patch than the pack's core Create version, so this is a
  common source of "why won't it load" bugs)
