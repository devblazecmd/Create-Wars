# BadOptimizations

**Source:** [Modrinth](https://modrinth.com/mod/badoptimizations)

## Role in Create Wars
Collection of micro-optimizations (redundant light-map upload cancellation, sky-colour calculation
caching, skipped pointless packet serialization). Individually small, cumulatively meaningful in a
heavy modpack like this one — called out specifically as helpful for packs with Create contraption-driven
tick load.
