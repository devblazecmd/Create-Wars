# Flywheel

**Source:** [Create Wiki: Depending on Create](https://wiki.createmod.net/developers/depend-on-create/neoforge-1.21.1) · [maven.createmod.net](https://maven.createmod.net)

## Role in Create Wars
Rendering engine that Create uses for its contraption/kinetic block rendering. Not optional — [[Create]]
requires it directly.

## Dependencies
- Hard requires: none beyond NeoForge itself
- Required by: [[Create]]

## Version notes
Create's own wiki lists Flywheel 1.0.6 as the paired version for NeoForge 1.21.1; the Create maven also
shows 1.0.2 builds. **Pin whatever version packwiz/the Create mod page says is current at install time** —
don't hand-pick a version number from this note without cross-checking, since Flywheel/Create version
pairing is exactly the kind of thing that breaks silently across patch versions.
