# Sophisticated Storage Create Integration

**Source:** [Modrinth](https://modrinth.com/mod/sophisticated-storage-create-integration)

## Role in Create Wars
Makes [[Sophisticated Storage]] chests/barrels keep their full behavior (upgrades, filters, tiers) when
assembled into moving Create contraptions — i.e. cargo holds on [[Create Aeronautics]] airships,
[[Steam 'n' Rails]] trains, and tanks. Project owner prefers the Sophisticated family as the pack's main
storage paradigm (2026-11-20), so this is the vehicle-side half of that choice.

## Dependencies
- Hard requires: [[Sophisticated Core]], [[Sophisticated Storage]], [[Create]]

## Version notes
Added via `packwiz modrinth add sophisticated-storage-create-integration` on 2026-11-20; resolved to
`1.21.1-0.1.23.246` (published 2026-10-12). The pack's Sophisticated Storage pin (`1.5.91.2127`, from
2026-09-01) is older than this addon — no version constraint is declared, but if it crashes on boot,
updating Sophisticated Storage/Core is the first thing to try.
