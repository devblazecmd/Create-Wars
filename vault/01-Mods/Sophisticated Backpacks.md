# Sophisticated Backpacks

**Source:** [Modrinth](https://modrinth.com/mod/sophisticated-backpacks)

## Role in Create Wars
Portable, upgradeable backpacks (filtering, auto-smelting/compacting, tank/battery upgrades, etc.) — the
mobile counterpart to [[Sophisticated Storage]]. Relevant to the "war" angle directly: a pilot in
[[Create Aeronautics]] gear or a [[Create Droneworks Simulated]] operator can carry ammo/fuel/spare parts
without needing to return to a base storage system.
