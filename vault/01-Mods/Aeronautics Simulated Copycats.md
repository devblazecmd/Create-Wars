# Aeronautics: Simulated Copycats

**Source:** [Modrinth](https://modrinth.com/mod/simulated-copycats)

## Role in Create Wars
Addon for [[Create Aeronautics]] adding copycat blocks with different *physical* properties (weight,
drag, etc.) so airships/vehicles can drift, crash, bounce, and survive differently depending on what
copycat material is used structurally. Directly relevant to vehicle combat durability, not just aesthetics.

## Dependencies
- Hard requires: [[Create Aeronautics]]; packwiz found no new dependencies to add (already present).

## Version notes
Requested at `1.3.1`; `packwiz modrinth add` resolved to current latest, `1.3.2`.
