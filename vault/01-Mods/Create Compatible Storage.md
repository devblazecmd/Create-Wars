# Create: Compatible Storage

**Source:** [Modrinth](https://modrinth.com/mod/create-compatible-storage)

## Role in Create Wars
Compat fixes so modded chests behave correctly on moving Create contraptions. Insurance for the vehicle
cargo use case alongside [[Sophisticated Storage Create Integration]] — every vehicle in this pack is a
contraption, so storage-on-contraption bugs would hit constantly.

## Dependencies
- Hard requires: [[Create]]

## Version notes
Added via `packwiz modrinth add create-compatible-storage` on 2026-11-20; resolved to
`2.14.0-mc1.21.1-neoforge`. GPL-3.0.

## Known issues
Possible overlap with [[Sophisticated Storage Create Integration]] if both try to handle Sophisticated
containers on contraptions — check in-game.
