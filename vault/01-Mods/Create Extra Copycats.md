# Create: Extra Copycats

**Source:** [Modrinth](https://modrinth.com/mod/extra-copycats)

## Role in Create Wars
Small addon adding a few more copycat blocks: Copycat Collapsible (squash/stretch on the fly with a
Wrench) and Copycat Cabinet Door (thin 1x1 hinged door matching any block). Purely aesthetic/building QoL —
no combat/vehicle/radar role.

## Dependencies
- Hard requires: [[Create]]'s copycat system; packwiz found no new dependencies to add, so it likely hooks
  into Create's built-in copycats rather than requiring [[Aeronautics: Simulated Copycats]] or a separate
  "Copycats+" mod. Confirm in-game if blocks don't appear.
