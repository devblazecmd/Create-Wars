# Create: TFMG Community Edition

**Source:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/tfmg-community-edition) · source at [github.com/wolfieboy09/Create-TFMG-CE](https://github.com/wolfieboy09/Create-TFMG-CE)

## Role in Create Wars
Community-maintained fork of Create: The Factory Must Grow (original by DrMangoTea), aiming to fix bugs
ahead of eventual merge back into the official mod. Adds industrial-scale content on top of Create: oil
processing, large transformers/switches, electricity — a heavier industry layer to fuel large-scale
production (cannon ammo, drone parts, etc.) beyond vanilla Create.

**Distribution note:** the project's source lives on GitHub, but as of 2026-09-01 that repo has **no
published GitHub Releases** — the actual distributed builds are on CurseForge only. Pinned via
`packwiz curseforge add`, not `packwiz github add`. Re-check this if a future version bump fails; the
distribution channel may have changed.
