# Create Waystones Recipes

**Source:** [Modrinth](https://modrinth.com/mod/create-waystones-recipes)

## Role in Create Wars
Reworks [[Waystones]] recipes to use Create resources and rebalances them. Fast-travel between bases is
relevant for a "war" pack — worth deciding whether teleport convenience undercuts the point of
[[Create Aeronautics]]/[[CBC Aeronautics Missiles]] vehicle travel, or whether it's balanced by cost via
this mod's recipe changes.

## Dependencies
- Hard requires: [[Waystones]] (auto-resolved and added by packwiz — this is the first thing that pulled
  the base Waystones mod into the pack)
- Also hard requires [[Balm]] — not declared on Modrinth, only surfaced as a hard crash during a headless
  server boot test; see [[Balm]]'s note.
