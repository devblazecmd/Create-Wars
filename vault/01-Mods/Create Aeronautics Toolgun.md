# Create Aeronautics: Toolgun

**Source:** [Modrinth](https://modrinth.com/mod/create-aeronautics-toolgun)

## Role in Create Wars
Adds a gravity gun with towing functionality, a toolgun for fast saving/printing physical-structure
blueprints, and other utilities. Directly useful for vehicle logistics (towing a downed/damaged
[[Create Aeronautics]] contraption back to base) and for rapidly rebuilding standard vehicle/turret
blueprints after combat losses.

## Dependencies
- None required by packwiz at add time; functionally tied to [[Create Aeronautics]] contraptions.

## Version notes
Added via `packwiz modrinth add create-aeronautics-toolgun` on 2026-09-01; resolved to `0.3.6`, one patch
above the requested `0.3.5`.
