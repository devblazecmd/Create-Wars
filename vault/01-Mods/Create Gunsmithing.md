# Create Gunsmithing

**Source:** [Modrinth](https://modrinth.com/mod/cgs)

## Role in Create Wars
Steampunk personal firearms crafted through Create machinery. Fills the infantry gap: until now all combat was cannons/missiles/vehicles. Serves both PvP and the PvE side (players need a handheld answer to [[Improved Mobs]]/[[Enhanced AI]] mobs).

## Dependencies
- Hard requires: [[Create]], [[NTGL NukaTeam's Gun Lib|NTGL]]
- Required by: [[Trigger Mobs]]

## Version notes
Added via `packwiz modrinth add cgs` on 2026-11-20; resolved to `1.4.9`.

## Known issues
Ships its own steel recipes - check for overlap with [[Create TFMG Community Edition|TFMG]] steel once in-game (a compat datapack exists on Modrinth for Alloyed's steel, which suggests steel duplication is a known pattern).
