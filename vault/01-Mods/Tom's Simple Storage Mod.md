# Tom's Simple Storage Mod

**Source:** [Modrinth](https://modrinth.com/mod/toms-storage) · author tom5454

## Role in Create Wars
"Simple vanilla-style" storage: Storage & Crafting Terminal, Inventory Connector, Open Crate, Wireless
Terminal, filtered connectors, Inventory Hopper. Alongside [[Sophisticated Storage]]/
[[Sophisticated Backpacks]], gives a second storage paradigm — Tom's Storage centers on a networked
terminal/connector system rather than individual upgradeable containers. Paired with
[[Create Contraption Terminals]] for Create-contraption integration, per the user's explicit request for
"Tom's Simple Storage with Create integration."

## Dependencies
- None required by packwiz at add time (standalone base mod).
- [[Create Contraption Terminals]] extends this specifically for Create contraptions — added alongside it.
