# FastFurnace

**Source:** [Modrinth](https://modrinth.com/mod/fastfurnace)

## Role in Create Wars
Caches the last smelting recipe per furnace type and skips expensive recipe-matching logic when inputs
don't change — keeps large auto-smelter setups (common in Create-based factories) from spiking server tick
time.
