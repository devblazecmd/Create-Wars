# Create Contraption Terminals

**Source:** [Modrinth](https://modrinth.com/mod/create-contraption-terminals) · author tom5454

## Role in Create Wars
This is the actual "Create integration" for [[Tom's Simple Storage Mod|Tom's Simple Storage]]: lets its
Storage/Crafting Terminals work while placed on moving Create contraptions (trains, vehicles, airships).
Directly useful for [[Create Aeronautics]]/[[Hot's Aerostuff]] vehicle builds that need onboard storage
access while in motion.

## Dependencies
- Hard requires: [[Create]] (auto-resolved and added by packwiz, already present) and
  [[Tom's Simple Storage Mod|Tom's Simple Storage]] (installed alongside it, not auto-detected as a
  Modrinth dependency by packwiz — verify both are present if either is ever removed).
