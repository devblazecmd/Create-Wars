# Curios API

**Source:** [Modrinth](https://modrinth.com/mod/curios)

## Role in Create Wars
Accessory slot API (head, back, belt and so on). It has no content of its own, but it adds extra
equipment slots to the inventory screen.

## Dependencies
- Hard requires: NeoForge `[21.1.265,)` (pack is on 21.1.267; any downgrade below 265 breaks it)
- Required by: [[Thick Air]] (Respirator in the head slot)

## Version notes

`9.6.0+1.21.1`. Checked that no other mod bundles Curios as jar-in-jar.
