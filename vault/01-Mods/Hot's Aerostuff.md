# Hot's Aerostuff

**Source:** [Modrinth](https://modrinth.com/mod/hots-aerostuff) · author HotElbows

**Naming note:** requested as "hotstuff-1.1.6" — this is *not* the abandoned "Create: Hot Stuff" addon
(which only ever shipped for MC 1.20.1 and adds molten-metal casting). It's "Hot's Aerostuff," whose actual
jar filename happens to be `hotstuff-x.y.z.jar`. Confirmed by cross-checking CurseForge's file list for both
projects before adding — don't let a future re-search of "hot stuff" pull in the wrong, dead mod.

## Role in Create Wars
Addon for [[Create Aeronautics]] ("a rabble of new Aeronautics bits"): adds a link relay, redstone levitite,
copycat sails, copycat symmetric sails, and an analog torsion spring. Vehicle-building content, in the same
vein as [[Create Compact Flap]] and [[Aeronautics: Simulated Copycats]].
