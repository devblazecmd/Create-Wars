# Create Aeronautics

**Source:** [Modrinth](https://modrinth.com/mod/create-aeronautics/versions) · [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-aeronautics)

## Role in Create Wars
Adds planes, drones, hot-air balloons, cars, trucks, and other contraption-based vehicles. Split into three
content sections: **Simulated** (assembly/redstone tooling for simulated contraptions), **Aeronautics**
(flight via hot air, propellers, floating rocks), and **Offroad** (land vehicles). This is the base layer
that [[Create Droneworks Simulated]] builds its actual drone control on top of.

Decided 2026-09-01: this covers the vehicle/movement role that [[Valkyrien Skies (unofficial port)|Valkyrien
Skies]] would otherwise have filled, so VS was rejected rather than run alongside it — one less unofficial,
unsupported dependency to carry through future MC version bumps.
